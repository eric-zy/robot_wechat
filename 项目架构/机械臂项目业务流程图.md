# 微信机器人项目 — 完整业务流程图

---

## 一、项目总览

```
paid_project/paid/
├── paid.lua                 ← 主控调度中心 (1控N, 轮询所有通道)
├── process_one.lua          ← 单通道任务调度器 (按顺序执行各功能模块)
├── 脚本/
│   ├── config.lua           ← 全局配置 (API地址、坐标、功能开关)
│   ├── common.lua           ← 公共函数库 (核心中转, 挂载各子模块)
│   ├── mass_send.lua        ← 群发助手流程 (msg_type=1/2, mass_send_area=0/1)
│   ├── favorite_mass_send.lua ← 收藏群发流程 (content_type=4 或 task_type=3 触发)
│   ├── init_favor.lua       ← 收藏资源同步 (独立流程, 无开关控制)
│   ├── tag_task.lua         ← 好友标签任务 (无开关控制)
│   ├── moments_task.lua     ← 朋友圈发布任务 (无开关控制)
│   ├── get_wechat_msg_v2.lua ← 微信聊天消息处理 (CHAT开关控制)
│   ├── manual.lua           ← 主动干预话术 (无开关控制)
│   ├── requests.lua         ← HTTP请求封装
│   ├── utils.lua            ← 工具函数 (日志上传等)
│   ├── main.lua             ← 打开微信入口
│   └── open_controller.lua  ← 多控助手启动
└── 界面/ 资源/ 插件/        ← 辅助资源
```

### 功能开关一览

| 步骤 | 功能 | 开关变量 | 是否总能执行 | 说明 |
|:----:|------|----------|:---:|------|
| 0 | 打开微信 | 无 | ✅ | 基础前置 |
| 1 | 加好友 | `ADD_FRIEND` | ❌ | 服务端控制 |
| 2 | 收藏同步 | 无 | ✅ | 独立流程 |
| 3 | 聊天 | `CHAT` | ❌ | 服务端控制 |
| 4 | 主动群发 | `MASS_SEND` | ❌ | 服务端控制 |
| 5 | 回访群发 | 条件 `pay=2 & addr=0` | ❌ | 条件触发 |
| 6 | 好友标签 | 无(已注释) | ✅ | 总是执行 |
| 7 | 朋友圈 | 无(已注释) | ✅ | 总是执行 |

## 五、群发流程 — 总路由 (mass_send.lua → massSendFlow)

```
┌──────────────────────────────────────────────────────────────────┐
│                 runMassSendTask(msg_type)                          │
│                 └→ massSendFlow()                                  │
└────────────┬─────────────────────────────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────────────────────────┐
    │  STEP 1: getMassSendContacts() 获取联系人和任务数据        │
    │                                                           │
    │  msg_type=1 → GET /api/reminder/next (回访用户列表)        │
    │  msg_type=2 → GET /api/mass_send/records/by_channel (群发) │
    │                                                           │
    │  ↓ 返回 contacts[], task_data, robot_code, channel_num    │
    │  ↓ contacts为空 → interruptCleanup → 返回                 │
    └────────────┬─────────────────────────────────────────────┘
                 │
                 ▼
    ┌──────────────────────────────────────────────────────────┐
    │  STEP 2: 路由判断 (按优先级)                               │
    └────────────┬─────────────────────────────────────────────┘
                 │
      ┌──────────┼──────────┐
      ▼          ▼          ▼
    ┌─────┐  ┌──────┐  ┌──────────────────┐
    │分支A│  │分支B │  │分支C+D (默认)      │
    └──┬──┘  └──┬───┘  └────────┬─────────┘
       │        │                │
       │        │                ▼
       │        │    ┌─────────────────────────────┐
       │        │    │  分支C: task_type==3         │
       │        │    │  └→ 收藏群发(兼容旧逻辑)      │
       │        │    │  └→ favorite_mass_send.run() │
       │        │    ├─────────────────────────────┤
       │        │    │  分支D: 默认                 │
       │        │    │  └→ 普通群发助手(见 [六])      │
       │        │    └─────────────────────────────┘
       │        │
       │        ▼
       │  ┌─────────────────────────────┐
       │  │ 分支B: content_type==4      │
       │  │ └→ 模板包含收藏类型          │
       │  │ └→ favorite_mass_send.run() │
       │  └─────────────────────────────┘
       │
       ▼
  ┌─────────────────────────────────────────┐
  │ 分支A: mass_send_area == 1               │
  │ └→ 全部人员群发模式                      │
  │                                          │
  │  ① clickNewMassSend() 进入选择界面        │
  │  ② selectAllContactsAndBuildRecords()    │
  │     └→ 逐屏OCR→全选联系人→构建records     │

  │  ④ sendViaMassSendAssistant() 群发助手    │
  │  ⑤ reportDeviceRecords()                 │
  │     └→ POST /api/mass_send/device/records │
  │  ⑥ updateMassSendRecordStatus()          │
  │     └→ POST /api/mass_send/update_send_status
  │  ⑦ 返回微信列表                          │
  └─────────────────────────────────────────┘
```

## 六、群发助手发送流程 (sendViaMassSendAssistant)

```
┌──────────────────────────────────────────────────────────────────┐
│          sendViaMassSendAssistant() — 群发助手发送                 │
│  前置条件: 已在群发助手→联系人选择完成→已点击"选中"                │
└────────────┬─────────────────────────────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────────────┐
    │  STEP 1: 进入群发助手编辑界面                  │
    │  └→ OCR找"输入内容"→ 点击进入                 │
    └────────────┬─────────────────────────────────┘
                 │
                 ▼
    ┌──────────────────────────────────────────────┐
    │  STEP 2: 调用后端获取消息                      │
    │  msg_type=2 → GET /api/mass_send/send_to_id   │
    │  └→ 后端将消息发送到ID号                      │
    │  msg_type=1 → GET /api/reminder/next          │
    │  └→ 获取回访消息内容                          │
    └────────────┬─────────────────────────────────┘
                 │
                 ▼
    ┌──────────────────────────────────────────────┐
    │  STEP 3: 切换到ID号, 获取消息列表              │
    │  └→ 从桌面打开ID应用                          │
    │  └→ OCR搜索进入与ID的聊天                     │
    │  └→ getIDMessages() 获取消息位置               │
    └────────────┬─────────────────────────────────┘
                 │
                 ▼
    ┌──────────────────────────────────────────────┐
    │  STEP 4: 逐条处理 send_results                │
    │  └→ for each msgItem in sendResults           │
    │      │                                        │
    │      ├─ [公共] 切回ID → 获取消息列表            │
    │      │   └→ 非首条: 快速切换(桌面点ID图标)      │
    │      │   └→ 首条: 完整初始化                   │
    │      │                                        │
    │      ├─ content_type=1 (文字)                  │
    │      │   └→ ID端长按复制                      │
    │      │   └→ 切微信→群发助手→粘贴              │
    │      │   └→ 检测"发送"按钮→点击              │
    │      │                                        │
    │      ├─ content_type=2/3 (图片/视频)           │
    │      │   └→ ID端点击预览→三点菜单→保存到手机    │
    │      │   └→ 退出预览                          │
    │      │   └→ 切微信→群发助手→+号→相册         │
    │      │   └→ 选第一张→点相册发送                │
    │      │   └→ 延迟2~3s→再检测发送按钮→补充点击   │
    │      │                                        │
    │      └─ 其他 content_type → 打印暂不支持, 跳过  │
    └────────────┬─────────────────────────────────┘
                 │
                 ▼
    ┌──────────────────────────────────────────────┐
    │  STEP 5: 发送成功, 更新状态                    │
    │  └→ POST /api/mass_send/update_send_status    │
    │  └→ 参数: records[{id, status=1}]             │
    └──────────────────────────────────────────────┘
```

## 七、聊天消息处理流程 (get_wechat_msg_v2.lua)

```
┌──────────────────────────────────────────────────────────────┐
│              startFindMsg() — 聊天消息检测与回复                │
│  触发条件: CHAT开关 = true                                     │
└────────────┬─────────────────────────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────┐
    │ ① 初始化参数                         │
    │    maxUnreadCount = 最多处理未读条数   │
    │    maxSwipeTimes   = 最多滑动次数     │
    │    msg_type_config = 消息类型配置      │
    └────────────┬─────────────────────────┘
                 │
                 ▼
    ┌──────────────────────────────────────┐
    │ ② 打开微信, 确保在消息列表页面         │
    └────────────┬─────────────────────────┘
                 │
                 ▼
    ┌──────────────────────────────────────┐
    │ ③ 循环检测红点 (未读消息)             │
    │    └→ OCR检测屏幕中红点/数字标记       │
    │    └→ 无红点 → 向上滑动刷新           │
    │    └→ 有红点 → 点击进入聊天           │
    │    └→ 超时/超滑动次数 → 退出          │
    └────────────┬─────────────────────────┘
                 │ 进入聊天
                 ▼
    ┌──────────────────────────────────────┐
    │ ④ OCR识别最新消息                    │
    │    └→ 识别对方发来的文字内容           │
    │    └→ 过滤系统消息(如"添加了朋友"等)   │
    └────────────┬─────────────────────────┘
                 │
                 ▼
    ┌──────────────────────────────────────┐
    │ ⑤ 调用AI接口获取回复                  │
    │    └→ POST /api/chat (设备端AI)       │
    │    └→ 传入: 对方消息 + 上下文         │
    │    └→ 返回: AI生成的回复内容           │
    └────────────┬─────────────────────────┘
                 │
                 ▼
    ┌──────────────────────────────────────┐
    │ ⑥ 在微信中粘贴发送AI回复              │
    │    └→ 点击输入框                      │
    │    └→ 粘贴AI回复内容                  │
    │    └→ 点击发送                        │
    │    └→ 等待发送完成(检测消息已发出)      │
    └────────────┬─────────────────────────┘
                 │
                 ▼
    ┌──────────────────────────────────────┐
    │ ⑦ 返回消息列表, 继续检测下一个红点     │
    │    └→ 循环直到:                       │
    │        - 没有更多未读消息              │
    │        - 达到 maxUnreadCount 上限     │
    │        - 达到 maxSwipeTimes 上限      │
    └──────────────────────────────────────┘
```

## 八、收藏资源同步流程 (init_favor.lua)

```
┌──────────────────────────────────────────────────────────────┐
│              initFavor() — 收藏资源同步                         │
│  触发条件: 无开关, 每个通道每次都执行                            │
│  目的: 将后端资源文件(图片/视频/文件)同步到微信收藏              │
└────────────┬─────────────────────────────────────────────────┘
             │
             ▼
    ┌──────────────────────────────────────────────┐
    │ ① getPendingSync()                           │
    │    GET /device/resource/pending_sync          │
    │    获取待同步的资源文件列表                    │
    │    ↓ 无待同步资源 → 跳过, 返回                │
    └────────────┬─────────────────────────────────┘
                 │ 有待同步资源
                 ▼
    ┌──────────────────────────────────────────────┐
    │ ② sendToFileHelper() 发送到文件传输助手       │
    │    └→ GET /device/resource/send               │
    │    └→ 后端将资源文件发送到ID号                │
    └────────────┬─────────────────────────────────┘
                 │
                 ▼
    ┌──────────────────────────────────────────────┐
    │ ③ 切换到ID号, 打开文件传输助手聊天             │
    │    └→ 获取刚发送的资源消息                     │
    └────────────┬─────────────────────────────────┘
                 │
                 ▼
    ┌──────────────────────────────────────────────┐
    │ ④ doSyncFavorites() 遍历资源逐个收藏          │
    │    for each resource:                         │
    │    ├─ 点击消息打开预览                         │
    │    ├─ 三点菜单 → OCR找"收藏" → 点击收藏        │
    │    ├─ 检测"已收藏"确认成功                     │
    │    └─ 退出预览                                 │
```

## 十二、群发助手 vs 收藏群发 路由对照

```
收到群发任务 (task_data)
│
├─ mass_send_area==1 ?
│   └→ [全部人员] 群发助手 (强制, 不判断其他条件)
│
├─ template_contents 包含 content_type=4 ?
│   └→ [收藏] favorite_mass_send.run()
│      └→ 进入微信收藏 → 多选收藏内容 → 转发 → 选联系人 → 发送
│
├─ task_type==3 ?
│   └→ [收藏-旧逻辑] favorite_mass_send.run()
│
└─ 默认 (type=1/2/3, content_type=1/2/3)
    └→ [群发助手] sendViaMassSendAssistant()
       └→ ID端获取消息 → 复制/保存 → 微信群发助手粘贴/发送
```
